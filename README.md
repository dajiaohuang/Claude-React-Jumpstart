# Claude React Artifact Tutorial

Claude Artifacts can compile code in a dedicated window. This tutorial helps beginners run React code generated by Claude's Artifacts feature in a local React app.

[![Project Demo](https://img.youtube.com/vi/oRh_tVdgjB8/0.jpg)](https://www.youtube.com/watch?v=oRh_tVdgjB8)

> Claude-React-Jumpstart: A step-by-step guide to running Claude-generated React code locally.

---

## Getting Started
You can use the example provided to learn the process. Before beginning the following steps, remove the my-app folder so you can recreate it.

### Step 1: Create new React app with Vite

```bash
npm create vite@latest my-app
✔ Select a framework: › React
✔ Select a variant: › JavaScript
cd my-app
npm install
```

### Step 2: Install Tailwindcss and Shadcn

The included example uses Tailwind CSS 3. Pin that major version so the setup command below matches the example's configuration. Current Tailwind CSS 4 uses a different Vite setup; see [the Tailwind CSS Vite guide](https://tailwindcss.com/docs/installation/using-vite) if you want to migrate the example.

```bash
npm install -D tailwindcss@3 postcss autoprefixer
npx tailwindcss@3 init -p
```

For the current shadcn/ui Vite setup, see [the Vite installation guide](https://ui.shadcn.com/docs/installation/vite).

Update `vite.config.js`:

```javascript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import path from 'path'

export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './src'),
    },
  },
})
```

Create `jsconfig.json`:

```json
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["src/*"]
    }
  },
  "include": ["src/**/*"]
}
```

```bash
npx shadcn@latest init
```

The CLI package is `shadcn` (without `-ui`). To generate JavaScript components, set `"tsx": false` in the generated `components.json` before adding them. See [shadcn/ui's JavaScript guide](https://ui.shadcn.com/docs/javascript).

### 3. Install Other Libraries and Components
Choose your list of required components and libraries to download based upon the imports in your react file.
```bash
npx shadcn@latest add card button input
npm install lucide-react
```

### 4. Add Your Artifact Code

`LLMModel.jsx` is an included artifact example. You can move the file to `src/components/LLMModel.jsx`.

Then add it to your app by updating `App.jsx`:

```jsx
import './App.css'
import LLMModel from './components/LLMModel'

function App() {
  return (
    <>
      <LLMModel/>
    </>
  )
}

export default App
```

### 5. Run the App

```bash
npm run dev
```
